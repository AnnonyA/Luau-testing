✳ YOUR WORKSPACE, YOUR MACHINE

Ready when
you are.

Run Studio locally with Rust. Your files go to the server you run, not to this website.

Read the setup guide ↗
QUICK STARTLOCAL / TERMINAL
01

Clone the repository

git clone https://github.com/AnnonyA/Luau-testing.git
02

Start the server

cd Luau-testing && cargo run --release -p web-server
03

Open your workspace

http://127.0.0.1:3000 ↗

Requires Rust and rustup. First build may take a few minutes.
