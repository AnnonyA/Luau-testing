# Large semantic stress corpus

39 original deterministic fixtures: seven larger foundational cases and 32
stateful mixed-feature programs (`adversarial_00`–`31`). The latter permute 16
constructs and revisit four of them, so mutations in earlier blocks affect later
closures, branches and tables. They cover stateful custom iterators, nested
loops, coroutine resume/yield, protected errors, recursive calls, aliasing and
multiple assignment, captured variables, multi-return and open constructors,
short circuiting, bitwise operations, NaN, and table metamethods. Sources are
checked in and regenerated byte-for-byte by `generate_cases.py` and
`generate_adversarial.py`; they remain synthetic, not a representative sample
of every project.

Each program returns a function. The sandbox runs 11 seeds per profile, checks
return arity including nil, and compares the complete event trace with the
original. A deliberate `total` mutation per case must change the observation.
Six profiles cover bytecode 9 and 12 and O0/g0, O1/g1 and O2/g2, all with
`--fflags=false`. Finite inputs are not proof of equivalence. The VM has no
filesystem or network, and has runtime and memory limits. Native decompilation
has a wall timeout and, on Linux, process memory and output limits.

Build the compiler and VM using the pinned Luau revision documented in
`scripts/benchmark_vm/CMakeLists.txt`, then run:

```sh
python3 scripts/stress_roundtrip.py --compiler /path/to/luau-compile \
  --vm /path/to/benchmark-vm --native /path/to/luau-lifter --out out/stress-native
```

Use `--case adversarial_00` to run one case, or `--shard 0/4` to select a
zero-based partition (repeat with indices 1, 2, and 3). Without `--native` it
runs the checked-in upstream browser WASM, not the branch's native decompiler.
The native runner uses `decompile-folder` with key 1. `report.json` and
per-profile outputs live in the new output directory; mismatches preserve
original and observed traces. Exit 1 means a profile did not pass, 2 means the
harness itself failed. CI builds this branch's native CLI, runs four shards,
and uploads one artifact per shard, even on failure. The reports hash tools,
sources and bytecode, but the runner itself does not verify the compiler commit.

`browser_baseline.json` and [native run 45076486459](https://github.com/AnnonyA/Luau-testing/actions/runs/45076486459)
are **historical** results for seven cases, five seeds, and four profiles. They
predate the expanded corpus and current driver. The browser baseline uses the
upstream WASM at `bd8055d`, not the current branch. No external code is sent.
